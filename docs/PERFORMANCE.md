# 性能优化记录（桌面版）

> 目标：降低桌面版空闲资源占用、减少无谓 UI 重排与进程/文件扫描，提升长时间挂机稳定性。

## 测量方法

- 桌面进程：`Get-Process WXBOT` 的 `TotalProcessorTime`、`WorkingSet64`、`PrivateMemorySize64`，以及 `GetGuiResources`（GDI/USER）。
- 后台服务：supervisor.json 中四个子进程的 WorkingSet 总和。
- 采样窗口：空闲 15 秒，取 CPU 平均占用。

## 已做优化

1. **字体复用**：会话列表、气泡头/正文、头像改为静态 Font 对象，避免每次绘制/重建气泡时创建 Font（GDI 资源）。
2. **图片缓存 LRU**：最多缓存 64 张图片，超出后释放最旧图片，避免长挂机图片消息把内存吃满。
3. **控件释放**：刷新聊天前 `Dispose()` 旧气泡控件；图片淘汰时 `Dispose()`，避免 GDI/Image 泄漏。
4. **定时器降负**：
   - 窗口最小化或打开设置面板时，跳过 meta/会话/聊天刷新；
   - 登录状态轮询从 2.5s 调到 3s。
5. **进程/版本探测缓存**：微信进程列表缓存 3s、客户端文件版本缓存 30s，减少每 3s 枚举进程与读 PE 版本。
6. **状态区去重**：右侧运行状态 RichTextBox 仅在 services/model/deliveries 变化时重排；登录卡文本也做差异更新，减少布局与重绘。
7. **仅在有会话时轮询消息**：保留 3s 聊天轮询，但内容未变化时不重建气泡（原有 JSON 对比逻辑保留）。
8. **消除残留控制台窗口**：桌面进程启动时若控制台属于本进程（双击/无父终端），调用 `FreeConsole()` 销毁私有控制台，不再残留 `PseudoConsoleWindow` / `conhost.exe`；从 PowerShell 调用 CLI 时保留父控制台，`--selftest` 等输出正常。

## 设置/主界面切换与滚动条（2026-10-18 追加）

- 设置保存重启从 UI 线程移出，`RunManage("restart")` 异步执行；
- 服务操作期间暂停定时刷新，操作结束只刷新状态/会话，不重建聊天；
- 设置覆盖层启动后预热，首次打开从 157ms 降到 38ms，后续 10–13ms；
- 设置→主界面从 240–286ms 降到 7–14ms（实测点击处理耗时）；
- 统一 8px 深色细滚动条，移除原生 `WS_VSCROLL`，修复滚动时第二条滚动条闪烁；
- 回归：停止/启动/设置保存重启 UI 阻塞采样 0/107，最大延迟 13ms；
- 运行状态面板改为 `FlowLayoutPanel + Label`，右栏加宽到 400px，所有状态信息可换行完整显示/滚动；
- 通过 `NativeWindow` 钩子强制移除原生 `WS_VSCROLL`，滚动时不再出现第二条原生滚动条闪烁。
